# 智能差旅费报销项目汇报

## 项目概述

本项目建设了一套公司内部钉钉差旅报销工具，将出差审批关联、材料上传、票据识别、费用核对、自动保存、文件生成和 OA 提交整合到一个页面。

员工确认报销内容后，服务器自动生成票据汇总 PDF 和公司模板 Excel，上传至钉钉审批附件空间，创建正式 OA 并回读确认结果。系统负责到成功发起 OA，后续审批和财务处理仍在钉钉内完成。

## 解决的主要问题

| 原有痛点 | 项目解决方式 |
| --- | --- |
| 出差审批、公司、预算和报销信息分散，员工需要重复填写 | 从本人已通过的出差审批中带入公司、预算代码和关联源单，在同一页面完成核对 |
| 发票、车票、行程单、住宿明细和付款凭证整理耗时 | 提供统一上传入口，自动分类材料，优先读取 PDF 文本，必要时使用本地 OCR |
| 补助计算和材料要求较多，容易漏项或算错 | 补助、总额、票据数和人民币大写由后端重算，并按费用类型检查所需材料 |

## 员工使用流程

1. 钉钉免登，查询并选择本人已通过的出差审批。
2. 一次上传多份票据和证明材料，系统逐份校验、分类和识别。
3. 员工核对费用明细，补齐行程单、住宿明细或付款凭证。
4. 服务器重新计算金额，生成票据汇总 PDF 和报销单 Excel。
5. 服务器上传附件、创建钉钉 OA，并回读核对表单和附件。

## 项目亮点

- **一页完成业务闭环**：员工不再在审批、Excel 和附件上传之间反复切换；页面自动保存，刷新或换设备后可以恢复最近一笔报销。
- **本地识别并保留人工判断**：PDF 文本优先，本地 PaddleOCR 回退，不调用按次收费的 OCR 或大模型接口。证据不足时保留可编辑结果和核对提示。
- **服务端统一执行业务规则**：身份、公司、预算、补助、总额和票据数均以后端为准，避免前端篡改或不同端计算不一致。
- **提交过程可恢复且不重复**：不可变快照、幂等键、租约和检查点共同保护提交。结果不确定时转人工核对，避免重复 OA 或误删附件。
- **能够应对 OA 模板变化**：系统保存模板 Schema 指纹和配置版本，字段发生变化时阻止继续使用旧映射。

## 项目价值

- **对员工**：减少重复填写，材料缺失有明确提示，提交后可以看到处理进度和 OA 结果。
- **对财务**：统一报销单结构、金额口径和附件顺序，保留票据与费用明细的来源关系，减少来回核对。
