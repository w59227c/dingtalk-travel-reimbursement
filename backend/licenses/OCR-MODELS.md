# OCR model provenance

The image includes the unmodified official inference weights for
`PP-OCRv6_small_det` and `PP-OCRv6_small_rec` from PaddlePaddle.
Archive URLs and exact SHA-256 hashes are recorded in
`/app/app/ocr/model_manifest.json`. Only archive layout and file permissions
are normalized; weight contents are verified byte for byte.
